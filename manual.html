앱 시작 방법

모바일 폰과 워치에서 MotionTrace Pro를 시작하는 방법

📱 모바일 앱 실행

1

앱 설치

Google Play 스토어에서 "MotionTrace Pro"를 검색하여 설치합니다.

2

앱 실행

폰의 앱 목록에서 MotionTrace Pro 아이콘을 탭하여 실행합니다.

3

권한 허용

앱 실행 시 블루투스, 위치, 신체 활동 감지 권한을 요청합니다. 모두 허용해야 워치와 정상적으로 연결됩니다.

⌚ 워치 앱 실행

1

앱 목록 열기

갤럭시 워치의 앱 목록을 엽니다.(화면 아래에서 위로 화면 쓸어 넘기기)

2

MotionTrace Pro 선택

앱 목록에서 MotionTrace Pro 아이콘을 찾아 탭합니다.

3

초기 화면 확인

워치 화면에 클럽 선택 메뉴 와 템포 가 표시됩니다.

💡 폰의 MotionTrace Pro가 먼저 실행되어 있어야 워치 앱이 정상적으로 데이터를 수신할 수 있습니다.
💡 시작 순서 요약
① 폰에서 MotionTrace Pro 실행 → ② 워치에서 MotionTrace Pro 실행 → ③ 자동 블루투스 연결
2

모드 선택

Distance / Tempo / Putter — 스윙 목적에 맞는 모드를 선택하세요

폰 앱 상단의 모드 선택 버튼을 통해 분석 모드를 변경할 수 있습니다. 각 모드는 측정 항목과 AI 코치의 분석 기준이 다릅니다.

🔵 Distance 🟢 Tempo 🟠 Putter

DISTANCE 비거리 모드

목적: 임팩트 순간의 파워와 에너지 전이를 분석하여 비거리 향상을 돕습니다.

  • 집중 측정: 손 최대 가속도(G), 손목 회전 속도(dps), 손 감속 효율
  • AI 코치: 바이오메카닉스 전문가 관점에서 스윙 메커니즘 진단
  • 권장: 드라이버, 우드, 롱 아이언 샷 분석 시 사용

TEMPO 템포 모드

목적: 백스윙과 다운스윙의 리듬을 분석하여 일관된 스윙 타이밍을 만듭니다.

  • 집중 측정: 백스윙 시간, 다운스윙 시간, 템포 비율 (3:1 / 2:1)
  • AI 코치: 투어 프로 리듬 코치 관점에서 템포 진단
  • 프리미엄: 최근 10회 템포 일관성 트렌드 그래프 제공

PUTTER 퍼팅 모드

목적: 퍼팅 스트로크의 정교함과 거리 감각을 분석합니다.

  • 집중 측정: 페이스 컨트롤, 클로저 레이트, 예상 굴림 거리
  • AI 코치: 세계 최고 퍼팅 코치 관점에서 스트로크 진단
  • 특화: 퍼터 전용 물리 로직 (19.1× 스핀 계수, 페이스×1.0)
3

워치에서 측정 시작/종료 방법

화면 터치부터 데이터 전송까지 전 과정

⛳ 측정 순서

1

워치 화면 가운데 터치

워치 메인 화면 중앙 부분 을 탭합니다. 화면에 맨 위쪽에 "어드레스 대기" 메시지가 나타납니다.

2

어드레스 자세 취하기

클럽을 잡고 팔을 위로 올렸다 내려서 어드레스 자세를 취합니다. 워치가 자동으로 감지합니다.

3

팔을 내린 후 정지

팔을 내린 자세에서 2초간 정지 하면, 진동과 소리로 측정 신호가 발생합니다.

4

진동 + 소리 알림 🎯

정지가 감지되면 워치가 진동과 함께 "띠링" 소리를 냅니다. 이제 스윙을 시작하세요!

5

스윙 실행

평소대로 스윙합니다. 워치가 250Hz로 센서 데이터를 수집하여 폰으로 전송합니다.

6

스윙 후 자세 유지

스윙 후 진동 더블 + 종료 소리가 날 때까지 자세를 유지하세요. 소리가 나면 측정이 완료된 것입니다.

⚠️ 측정 종료 알림(더블 진동+소리) 전에 움직이면 데이터가 불완전할 수 있습니다.
🎵 소리 피드백 안내
측정 시작: 짧은 "삑" 1회 + 진동
측정 종료: "땡땡" 2회 + 진동 더블
이 소리들을 구분하여 스윙 타이밍을 맞추세요.
⚠️ 주의사항
· 측정 중에는 워치를 너무 세게 흔들거나 충격을 주지 마세요.
· 배터리 잔량이 부족하면 측정이 중단될 수 있습니다.
· 폰과 워치의 블루투스 연결이 끊어지지 않도록 가까이 두세요.

데이터 보는 방법

워치와 모바일 화면의 각 항목이 의미하는 바

⌚ 워치 화면 — 측정 결과 확인

스윙 직후 워치 화면에 다음과 같은 주요 결과가 표시됩니다.

항목 설명 좋은 기준
Club Speed 클럽 헤드 스피드 (워치 센서 기반 추정) 높을수록 좋음
Tempo 백스윙:다운스윙 비율 (3:1 또는 2:1 이상) 3:1 이상
Back / Down Time 백스윙 시간 / 다운스윙 시간 (초) 일관된 값
Decel Score (0~5) 손 감속 효율 점수 — 임팩트 순간 손이 얼마나 잘 멈췄는지 ⭐⭐⭐⭐⭐ 5점 만점
Border Color Decel 점수에 따른 테두리 색상 변화 (녹색=좋음, 빨강=나쁨) 초록색

📱 모바일 화면 — 상세 분석

폰 앱에서는 더욱 상세한 분석 결과와 시각화 데이터를 제공합니다.

항목 설명 세부 정보
🚀 손 최대 가속도 (G) 임팩트 순간 손의 가속도 (중력 가속도 G 단위) 높을수록 파워풀한 스윙
🔄 손목 회전 속도 (dps) 임팩트 전후 손목의 회전 각속도 페이스 컨트롤의 핵심 지표
🛑 손 감속 효율 스윙 중 손이 멈추면서 클럽 헤드로 에너지 전이되는 비율 비거리의 비밀 — 높을수록 좋음
📈 타이밍 그래프 스윙 전 구간의 가속도/회전속도 변화를 시계열 그래프로 표시 캐스팅 구간 식별 가능
🎯 구질 판정 페이스 각도 × 스윙 패스 조합으로 3×3 매트릭스 분석 페이드/드로우/훅/슬라이스 판별
📊 3D 스윙 궤적 스윙 궤적을 3D 공간에서 재구성한 시각화 멀티 앵글 회전/확대 가능
🤖 AI 코치 피드백 각 모드별 AI가 분석한 스윙 개선 포인트 Distance / Tempo / Putter 전문화

📊 스윙 구질 판정표 (3×3 매트릭스)

페이스 Open 페이스 Straight 페이스 Closed
In-to-Out Push Slice Push Draw
Straight Slice Straight ✨ Hook
Out-to-In Fade Pull Pull Hook
💡 Straight × Face Straight가 이상적인 정타입니다. 이 외의 조합은 구질 교정이 필요함을 의미합니다.

클럽 변경 기능

워치에서 현재 사용 중인 클럽을 변경하는 방법

🏌️ 워치에서 클럽 변경하기

1

워치 메인 화면 확인

워치 화면 상단(또는 중앙)에 현재 선택된 클럽 이름이 표시됩니다.

2

이전/다음 버튼 사용

워치 화면 좌우에 있는 ◀ / ▶ 버튼을 탭하여 클럽을 변경합니다.

3

클럽 목록

다음 12개 클럽 중에서 선택할 수 있습니다:

Driver 3 Wood 5 Wood 4 Iron ~ 9 Iron PW (Pitching Wedge) 56° Wedge Putter ⛳

🔄 클럽과 측정 시간

선택한 클럽에 따라 자동 녹화 시간이 달라집니다:

클럽 타입 녹화 시간 설명
Putter 약 4초 짧은 퍼팅 스트로크에 최적화
Full Swing (Driver/Iron/Wedge) 약 7초 풀스윙 전체 구간 포착
💡 클럽 변경은 자동으로 폰에 동기화됩니다. 워치에서 클럽을 바꾸면 폰 앱에도 즉시 반영되며, AI 코치가 해당 클럽에 맞는 분석을 제공합니다.
